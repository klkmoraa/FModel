# Colección ampliada de FModel / FModel expanded collection

Esta colección `.fmodellib` contiene 398 bloques CAD 2D convertidos al formato nativo de FModel.
Se distribuye con FModel y se instala localmente cuando el usuario lo solicita.

- Geometría original: [CADdillo block library](https://caddillo.com/blocks/), Quantum Armadillo, LLC.
- Licencia de la geometría: [CC0 1.0](https://caddillo.com/license/). La licencia cubre los bloques, no el software ni la marca CADdillo.
- Descarga del archivo fuente: https://caddillo.com/downloads/caddillo-blocks-library.zip
- Fecha de incorporación: 2026-09-18.
- SHA-256 del ZIP fuente: `9d5f35093e245158115aa5ead39d31d4b92253e2125b2751e2ef9c05e68e2d72`.
- Conversión: `scripts/build-cc0-thumbnails.py` y `scripts/build-cc0-library.mjs`; los DXF R2018 en pulgadas se transformaron en paquetes `.fmodellib` con categorías de FModel y miniaturas SVG. Esta conversión no implica que FModel haya creado la geometría original.

The bundled `.fmodellib` contains 398 2D CAD blocks converted to FModel's native library format. The original geometry is CC0 1.0; the source and conversion details are listed above. The CADdillo software and brand are not part of that dedication.
