Task 2 API in `src/model/wallAssembly.ts`:

- `WallAssemblySource extends WallPath { style: Id; owner: Id }` is the complete, current uncut wall; `WallAssembly` contains `source`, `groupId`, `anchorId`, ordered `members`, `roles: ReadonlyMap<string, Id>`, and `openings`.
- `readWallSource(doc: CadDocument, memberId: Id): { source: WallAssemblySource; anchorId: Id; assembly: WallAssembly | null }` accepts a compatible independent MLINE or any validated associated member. It performs structural validation, not editor layer/space permission checks.
- `readWallAssembly(doc: CadDocument, memberId: Id): WallAssembly` validates source schema/style/owner, group and exact ordered roles, member metadata and owners, and current geometry against the pure builder.
